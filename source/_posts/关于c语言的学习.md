### int main()  即为主函数 作为程序的入口 有且只有一个
(需要特别注意的是 如果一个项目内有多个.c文件 也只能有一个main函数)：

### size of 计算字符长度：
打印计算结果时 ... printf("%zu\n" , size of char)； ...
### 占位符：
%d 整数（十进制） %s 字符 
%c 字符          %p 指针(通常打印地址)
%f 小数          %x 整数(十六进制)   
%ld long int     %hd short int
### 变量：
data_type name ;（data_type为数据类型 name为变量名）
#### 变量的命名规则：
1.只能由字母、数字、“_”组成
2.不能以数字开头
3.变量名不能用关键字
(4.创建变量要初始化，即给变量一个初始值)
#### 变量的分类：
全局变量:{}之外
局部变量:{}之内，只能在相应的{}内使用
*当全局变量和局部变量冲突时，局部变量优先*
#### 变量的赋值：
... 
int a = 10 (初始化)
    a = 20 (赋值)
...
*连续赋值时，从右向左依次赋值,即右边等于左边(一般比较冗长，不推荐)*
#include <stdio.h>
int main()
{

    int a = 3;
    int b = 5;
    int c = 0;
    c = b = a + 3;
}     
#### 变量的复合赋值:
...
int a = 10;
    a =+ 3;
printf("%d\n", a);
...
* "+"、"-"、"*"、"/"、"%"通用*
即"a = a + 3" = "a += 3"
